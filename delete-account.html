Solicitud de eliminación

Esta es la página web destinada a recibir solicitudes de eliminación de cuentas de VENBOT AI.

Para solicitar la eliminación, envía un correo a soportevenbot@gmail.com. Esta vía no exige volver a instalar la aplicación para iniciar la solicitud.

Qué debe indicar la solicitud

  1. correo asociado a la cuenta;
  2. nombre visible, si aplica;
  3. solicitud expresa de eliminación;
  4. información adicional razonable para verificar la titularidad, cuando corresponda.

Qué ocurre con los datos

Cuando corresponda, VENBOT AI eliminará los datos asociados a la cuenta y dejará de tratarlos para la prestación del servicio. Algunos registros pueden conservarse cuando sea necesario por obligaciones legales, seguridad, prevención de fraude o resolución de disputas.

Suscripciones y pagos

Si existe un plan activo, podrán requerirse pasos adicionales para detener una renovación o resolver importes pendientes. La solicitud de eliminación y cualquier obligación de pago se gestionarán por separado cuando corresponda.

Ayuda

Para dudas sobre privacidad o eliminación, escribe a soportevenbot@gmail.com.
